# Корона

Android-приложение с камерой, которое распознаёт лицо человека и в реальном
времени добавляет корону и королевскую мантию. Готовый кадр сохраняется в
альбом `Pictures/Корона`.

## Возможности

- распознавание лица на устройстве с помощью ML Kit;
- задняя и фронтальная камеры;
- автоматическое позиционирование и плавное движение королевского образа;
- сохранение фотографии вместе с эффектами в системную галерею;
- фотографии не передаются на сервер.

## Запуск

1. Откройте корень проекта в Android Studio.
2. Дождитесь синхронизации Gradle.
3. Запустите конфигурацию `app` на устройстве с Android 10 или новее.
4. Разрешите приложению доступ к камере.

Для первой работы распознавания может понадобиться интернет: облегчённая модель
ML Kit устанавливается через Google Play Services. После загрузки обработка
выполняется локально.

## Технологии

Kotlin, Jetpack Compose, CameraX и Google ML Kit Face Detection.
