## Учебные материалы

Мини-сайт со школьными темами. Главная страница — `index.html`, разделы:

- `himiya/` — химия (`himiya/alkeny/` — алкены, 16 схем реакций);
- `geometriya/` — геометрия (`geometriya/sechenie-tetraedra/` — сечение тетраэдра, 3D-модель);
- `russkiy/` — русский язык (`russkiy/oboroty/` — игра «Миссия „Оборот“» про причастные и деепричастные обороты);
- `algebra/` — алгебра (готовится).

Сайт публикуется через GitHub Pages (`.github/workflows/pages.yml`) при push в `main`.
