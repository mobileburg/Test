# Тумба из липы в предбанник — 3D-визуализация

Два варианта в одних габаритах по замерам с фото (`reference.jpg`):

| Параметр | Значение |
|---|---|
| Длина | **129 см** |
| Высота | **90 см** (чтобы не перекрыть выключатель) |
| Глубина | **30 см сверху → 22 см внизу** (скос задней кромки под полукруглую стенку) |
| Выступ от проёма двери | 4 см (учтён в глубине) |
| Материал | мебельный щит липа 18 мм, цвет как у вагонки |

- **Вариант 1 — открытые полки.** Каркас + 2 или 3 полки.
- **Вариант 2 — комод с дверками.** Тот же каркас, две накладные распашные дверки с точёными деревянными ручками, внутри 2 или 3 полки.

## Файлы

| Файл | Описание |
|---|---|
| `index.html` | Интерактивная 3D-модель (Three.js). Переключение вариантов, число полок, открытие дверок, размеры, ракурсы |
| `renders/` | Готовые рендеры с размерами (8 ракурсов) |
| `concepts/` | Фотореалистичные концепты «как будет выглядеть на месте» (по референс-фото) |
| `reference.jpg` | Исходное фото с замерами |
| `render.sh` | Пакетный рендер ракурсов через headless Chrome |

## Просмотр

```bash
cd mebel-lipa
python3 -m http.server 8766
# открыть http://127.0.0.1:8766/
```

Параметры можно задать через URL, например:
`?variant=cabinet&shelves=3&doors=0.7&view=iso&ui=0`

- `variant` — `shelves` | `cabinet`
- `shelves` — `2` | `3`
- `doors` — `0…1` (степень открытия дверок)
- `view` — `iso` | `front` | `side` | `top`
- `dims`, `room`, `back` — `0`/`1` (размеры, стена и пол, задняя стенка)
- `ui=0` — скрыть панель управления

## Допущения модели

- Скос задней кромки боковин принят линейным: от 22 см у пола до 30 см у крышки. Если стенка реально полукруглая, по месту скос лучше снять шаблоном (картон) — геометрия каркаса от этого не меняется.
- Дно поднято на цоколь 6 см (под ним — плинтус и просвет для уборки), фасад цоколя утоплен на 3 см.
- Полки стоят равномерно; при 3 полках просвет ≈ 18 см, при 2 полках ≈ 25 см.
- В варианте с дверками полки утоплены на 2 см от фасада, дверки накладные на всю высоту между цоколем и крышкой; угол открытия до ~100°.
