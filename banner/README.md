# Рекламный баннер автошколы

Горизонтальный макет 3:2 (2400×1600) в стиле эффектной автомобильной рекламы:
фотореалистичный фон с белым седаном на фоне вечернего мегаполиса и чёрно-жёлтая
рекламная графика с точной кириллической типографикой.

## Состав

| Файл | Назначение |
| --- | --- |
| `index.html` | вёрстка макета: слои затемнения, типографика, иконки, генерация кистевых мазков |
| `prepare_bg.py` | кадрирование фотоподложки до 3:2 и масштабирование до 2400×1600 |
| `render.py` | рендер макета в PNG через headless Chrome (Playwright) |
| `fonts/` | локальные шрифты Oswald и Caveat с кириллицей + `localize.py` для их обновления |
| `assets/bg.jpg` | подготовленная фотоподложка |
| `out/` | готовый баннер в PNG и JPG |

Текст набран системой, а не сгенерирован нейросетью, поэтому все надписи
гарантированно читаемы и написаны без ошибок. Фотоподложка сгенерирована
отдельно и не содержит текста.

## Сборка

```bash
pip install pillow playwright
python3 prepare_bg.py   # нужен исходный кадр, путь задан в SRC
python3 render.py       # out/banner-avtoshkola.png
```

Кистевые мазки, потёртости и брызги строятся в `index.html` процедурно с
детерминированным генератором (`mulberry32`), поэтому повторный рендер даёт
идентичный результат; за форму каждого мазка отвечает атрибут `data-seed`.

## Шрифты

- **Oswald** — узкий гротеск для заголовков, плашек и подписей (с наклоном через `skewX`).
- **Caveat** — рукописный кистевой шрифт для эмоциональной строки «Твой путь к».

Оба шрифта распространяются по лицензии SIL Open Font License 1.1.
