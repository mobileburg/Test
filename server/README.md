# Серверная часть: статистика обучения

Сайт работает на GitHub Pages, а там нет своего сервера. Поэтому журнал и статистика ученика хранятся в Google-таблице, которую обслуживает бесплатный скрипт Google Apps Script.

Пока сервер не подключён, статистика пишется только в браузер того устройства, где ученик вошёл на сайт.

## Подключение (один раз)

1. Откройте [Google Таблицы](https://sheets.new) и создайте пустую таблицу, например «Учебный портал — статистика».
2. В меню выберите **Расширения → Apps Script**.
3. Удалите всё в файле `Code.gs` и вставьте содержимое файла [`apps-script.gs`](apps-script.gs). Сохраните.
4. Вверху выберите функцию **setup** и нажмите **Выполнить**. Google попросит разрешение на доступ к таблице — разрешите. Функция создаст лист `events` и сохранит логин `Dima` и пароль `Dimas` в свойствах скрипта.
5. Нажмите **Начать развертывание → Новое развертывание**, тип — **Веб-приложение**:
   - «Запуск от имени» — **Я**;
   - «У кого есть доступ» — **Все**.
   Нажмите **Начать развертывание** и скопируйте адрес веб-приложения (заканчивается на `/exec`).
6. Вставьте этот адрес в файл [`assets/portal-config.js`](../assets/portal-config.js):

   ```js
   window.PORTAL_API = "https://script.google.com/macros/s/…/exec";
   ```

   После публикации сайта ученику нужно один раз выйти и снова войти — тогда браузер получит ключ доступа к серверу. События, накопленные до этого на устройстве, отправятся на сервер автоматически.

## Как поменять пароль

В редакторе Apps Script откройте **Настройки проекта → Свойства скрипта** и измените `PASSWORD` (и при желании `USER`). Затем поменяйте хеш `USER_HASH` в [`assets/portal.js`](../assets/portal.js): это SHA-256 от строки `логин_маленькими_буквами + "\n" + пароль`.

## Что записывается

- открытие страниц и время на каждой странице;
- вход и выход;
- «Миссия „Оборот“»: начало попытки, каждый ответ (тип задания, верно или нет), итог попытки (баллы, победа, щиты, длительность);
- геометрия: решённые задачи (фигура, время, подсказки, ошибочные проверки, подсмотрено ли решение), пропущенные задачи.

Всё это видно на странице «Прогресс обучения» и в самой Google-таблице.
