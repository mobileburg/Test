# Интерактивный каталог «БаниВам»

Демонстрационный интернет-раздел для линейки «Бани Квадро».

## Страницы

- `index.html` — каталог из семи моделей и общий 3D-конфигуратор;
- `furniture.html` — отдельная визуализация мебели из липы: шесть ячеек, полки и комод.

## Возможности

- параметрические модели бань длиной от 2 до 6 метров;
- одно, два или три отделения;
- вход с торца или сбоку;
- разрез корпуса, подписи помещений и открывающиеся двери;
- обзор снаружи, сверху и изнутри каждого помещения;
- ссылки, сохраняющие модель, вход, ракурс и положение дверей;
- адаптивное управление мышью и касанием.

## Локальный запуск

ES-модули браузера требуют HTTP-сервер:

```bash
python3 -m http.server 8765
```

Открыть:

- `http://127.0.0.1:8765/bani-vam/`
- `http://127.0.0.1:8765/bani-vam/furniture.html`

Three.js и шрифты загружаются из CDN. Для боевого сайта их лучше разместить на собственном домене.

## Ограничения прототипа

Геометрия служит для демонстрации интерфейса и не является конструкторской документацией. Перед публикацией на `banivam.ru` нужно сверить размеры помещений, расположение печей, цены и комплектации с производством.
