# Мебель у полукруглой стены — липа

Два варианта корпуса **129 × 90 см**, глубина **30 см сверху → 22 см снизу**.

Цвет и фактура — светлая липа, в тон вагонки.

## Просмотр

```bash
cd mebel
python3 -m http.server 8766
# открыть http://127.0.0.1:8766/
```

Интерактивная модель крутится мышью. Кнопки переключают полки и комод, открывают дверки.

## Размеры

| Параметр | Значение |
|---|---|
| Ширина | 1290 мм |
| Высота | 900 мм (выключатель остаётся свободным) |
| Глубина сверху | 300 мм |
| Глубина снизу | 220 мм |
| Выступ от проёма двери | уже заложен в глубину, +40 мм |

Задняя плоскость скошена: фронт вертикальный, к полу корпус становится уже, чтобы встать к полукруглой стене.
