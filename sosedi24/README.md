# Соседи24

Мобильное приложение для знакомств с людьми поблизости. MVP определяет район по
геолокации устройства, показывает соседей в радиусе одного километра и позволяет
отправить приглашение дружить.

## Запуск

```bash
npm install
npm start
```

После запуска отсканируйте QR-код в Expo Go либо нажмите `a` для Android и `w`
для браузера.

## Возможности MVP

- явный запрос доступа к геолокации и демо-режим без неё;
- обратное геокодирование района на устройстве;
- список людей рядом, фильтры по интересам;
- отправка и отмена приглашений;
- вкладки друзей и профиля;
- пояснения о приватности геолокации.

Сейчас профили и заявки хранятся локально как демонстрационные данные. Для
продакшена потребуется API с авторизацией, базой пользователей, безопасным
поиском по геохешам и push-уведомлениями.
