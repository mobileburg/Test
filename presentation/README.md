# Презентация «Битриксуйте клиентские проекты»

Три слайда в фирменном стиле Битрикс24. Подготовлены два макета:

- горизонтальный 16:9 для просмотра на компьютере;
- вертикальный 9:16 для просмотра на телефоне.

## Готовые файлы

Все материалы находятся в каталоге `output/`:

- `Bitrix24_klientskie_proekty_PC_16x9.pptx`;
- `Bitrix24_klientskie_proekty_PC_16x9.pdf`;
- `Bitrix24_klientskie_proekty_Mobile_9x16.pptx`;
- `Bitrix24_klientskie_proekty_Mobile_9x16.pdf`;
- `Bitrix24_klientskie_proekty_materialy.zip` — общий архив для пересылки.

На третьем слайде размещён QR-код и активная ссылка на
`https://vk.ru/anchebykin`.

## Обновление файлов

```bash
python3 presentation/generate.py
```

Скрипт создаёт редактируемые PPTX-файлы. Для экспорта в PDF используется
LibreOffice.

## Фирменный стиль

- палитра: `#2FC7F7`, `#409EEF`, `#0066A1`, акцент `#BDF300`;
- шрифты: Montserrat и Open Sans;
- официальный логотип из пресс-кита Битрикс24.
